HTML - (Hyper Text Markup Language)

How Elements look/work by default (ahhh yes my eyes hurt too)

Paragraph - < p >

  • Structures text content to be on its own line
  • Any subsequent paragraphs (adding new < p > below existing one) creates and structures text on a new line below the previous 'paragraph' element

    • Paragraph 1 //// code: < p > Paragraph 1 < /p >

    Paragraph 2 //// code: < p > Paragraph 2 < /p >

Header - < h1...h6 >

  • Displays text in bolden and increased font
  • There are 6 variants, starting with < h1 > as the biggest
    • < h1 > example:

      Header 1

  • And ending with < h6 > as the smallest
    • < h6 > example:
      Header 6

List - < ol > or < ul >

  • Displays text in a list / bullet point format
  • There are two types: unordered < ul > and ordered < ol >
  • Each item on a list is enclosed with < li >

    • Example of ordered list:

    Top Five Poppy Playtime Characters

    1. The Prototype
    2. Poppy Playtime
    3. The Doctor
    4. CatNap
    5. Huggy Wuggy

    Example of unordered list:

    Cool Things I Like

    • Ninjago
    • The Gaslight District
    • Hollow Knight: Silksong
    • ENA
