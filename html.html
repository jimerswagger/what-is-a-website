HTML

How Elements look/work by default

Paragraph - < p >

  • Structures text content to be on its own line
  • Any subsequent paragraphs (adding new < p > below existing one) creates and structures text on a new line below the previous 'paragraph' element

    • Paragraph 1 //// code: < p > Paragraph 1 < /p >

    Paragraph 2 //// code: < p > Paragraph 2 < /p >

Header - < h1...h6 >

  • Displays text in bolden and increased font
  • There are 6 variants, with < h1 > as the biggest
    • < h1 > example:

      Header 1

  • And < h6 > as the smallest
    • < h6 > example:
      Header 6
